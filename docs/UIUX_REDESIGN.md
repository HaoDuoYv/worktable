# Worktable UI/UX 改版设计方案 v2

> 范围：桌面端（Electron / ≥1024px）+ 安卓端（Capacitor / <900px），两端共用同一套令牌、组件与动效规范，仅布局映射不同。
> 配套实现：`src/styles/motion.css`（动效系统）、`src/styles/overview.css`（主页 hero）、各页面 CSS 追加。

---

## 1. 设计概念 ——「每日简报 Daily Briefing」

主页从"后台管理仪表盘"改为"晨间简报"：打开应用的第一眼，先告诉你**今天的外部世界**（天气 + 热点），再呈现**你的进度**（统计 + 学习区）。这是本次改版唯一的信息层级翻转，也是视觉重心的落点。

三条设计原则：

1. **一屏一个主角**：首屏只突出 Hero 区（天气 + 热榜），其余内容全部降级为次级灰阶。
2. **静帧成立**：关掉所有动效后页面仍需成立——层级靠字号阶梯（温≥34px、h1 24px、卡题 15px、正文 13px）和明度差（panel/canvas 双层灰）实现，不依赖动画。
3. **动效服务层级**：入场顺序 = 阅读顺序（Hero → 统计 → 内容卡），用 stagger 把视线从上往下带。

## 2. 令牌层（Design Tokens）

沿用 `tokens.css` 既有体系，本次新增/明确以下令牌（全部双主题）：

| 令牌 | Dark | Light | 用途 |
|---|---|---|---|
| `--ease-out` | `cubic-bezier(0.16, 1, 0.3, 1)` | 同 | 入场/位移（快出缓停） |
| `--ease-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 同 | 按压回弹、Tab 激活 |
| `--dur-1 / 2 / 3` | `150 / 240 / 400ms` | 同 | 微交互 / hover / 入场 |
| `--stagger-step` | `60ms` | 同 | 入场阶梯间隔 |
| `--hero-temp-size` | `clamp(34px, 4vw, 44px)` | 同 | 天气主温度字号 |
| `--heat-grad` | `linear-gradient(135deg, #f85149, #ff7b42)` | `linear-gradient(135deg, #dc2626, #ea580c)` | 热榜 rank 徽标 / 火焰语义色 |

配色规则不变（VS Code 暗色体系 + 主题色预设 + 自定义主题全兼容）：Hero 区的"突出"来自**明度对比 + 少量语义色**（热度红橙渐变、天气 warn 琥珀、AQI signal 绿），不引入新色相，保证自定义主题导入后整体仍协调。

## 4. 动效规范（motion.css）

统一由 `src/styles/motion.css` 提供，全部 **CSS-only**（无运行时开销，Electron 与 WebView 双端一致）：

### 4.1 入场编排（页面加载播一次）

```css
.anim-rise { animation: rise-in var(--dur-3) var(--ease-out) both; animation-delay: calc(var(--i, 0) * var(--stagger-step)); }
@keyframes rise-in { from { opacity: 0; transform: translateY(14px); } }
```

- 顺序即阅读顺序：Hero 天气 `--i:0`、Hero 热榜 `--i:1`、统计条 `--i:2`、内容卡 `--i:3..5`。
- 组件内部列表行用同机制接续 stagger（`--i` 从父级 delay 之后继续）。
- **路由切换不重播**：入场动画只挂在内容块 class 上，React 重渲染同路由不会重启（动画在挂载时播）；跨路由跳转由浏览器原生的内容替换完成，不做过渡——这是刻意的，避免每次 Tab 都闪一遍。

### 4.2 微交互

| 对象 | 效果 | 参数 |
|---|---|---|
| 内容卡 `.panel` | hover 抬升 | `translateY(-2px)` + `border-color: line-strong` + `shadow-2`，`--dur-2 --ease-out` |
| 按钮/入口行 | 按压 | `:active scale(0.97)`，`--dur-1 --ease-spring` |
| 热榜行 | hover | 标题转 accent + rank 徽标轻微放大 `scale(1.12)` |
| 底部 Tab（安卓） | 激活 | 图标 `scale(1.1)` + accent，`--ease-spring` |
| TabBar/顶栏 | 滚动响应 | 保留现有毛玻璃，不加滚动动画 |
| 进度条 | 宽度过渡 | 已有 `width 0.4s` 保留 |

### 4.3 可达性兜底（硬约束）

- `prefers-reduced-motion: reduce`：`tokens.css` 已有全局 0.01ms 兜底，`motion.css` 内所有 keyframes 额外声明 `@media` 分支直接跳到终态。
- 触摸目标 ≥44px、`focus-visible` 焦点环不变。

## 5. 桌面 ↔ 安卓一致性映射

| 元素 | 桌面 | 安卓（<900px） |
|---|---|---|
| 导航 | 左侧栏 208px | 底部 5 Tab（现有结构不动） |
| Hero 区 | 双栏并排 | 单列堆叠，天气卡先行（更高频查看） |
| 动效 | 同一套 motion.css，鼠标 hover 生效 | hover 规则包在 `@media (hover: hover)` 内，触摸端只用按压反馈 |
| 安全区 | — | TabBar `env(safe-area-inset-bottom)` 已有，Hero 卡跟随页面 padding |

视觉令牌、字号阶梯、圆角、动效时长两端完全一致——安卓端只是布局重排，不是第二套设计。
