# 算法实验室左侧导航 — 简短设计说明

> 日期：2026-09-21 · 状态：**v2.1 已实现**（VS Code 文件树 + 右键 + 图标工具栏，verify 44/44）  
> 参考：algorithm-visualizer.org 左侧 Navigator  
> 范围：仅「算法库」左栏 IA；不改可视化/代码面板布局与动画协议本身。

## 1. 目标

左侧从「筛选按钮堆叠」改为 **搜索 → 分类树 → 低频操作沉底**，对齐 AV 的简洁感，同时保留 Worktable 本地算法管理能力。

## 2. 信息架构（已确认）

```
┌─────────────────────────┐
│ 排序 › 冒泡排序    ▾    │  可选：当前选中路径（紧凑）
├─────────────────────────┤
│ 🔍 搜索 …               │  唯一主筛选控件
├─────────────────────────┤
│ ▸ 排序 (n)              │  分类手风琴（来自 algorithm.category）
│ ▾ 链表 (n)              │
│   · 头尾插入与遍历  JS  │  展开后列出算法；语言作角标
│   · 双向链表        JS  │
│ ▸ 队列 (n)              │
│ …                       │
│ ★ 收藏                  │  伪节点：筛选 favorite
│ 👤 我的                 │  伪节点：筛选用户自建
├─────────────────────────┤
│ ＋ 新建算法             │  底栏主操作
│ ⋯ 更多                  │  导入 / 导出 / 多选
│ [JS|Py|C++]             │  紧凑语言开关（已确认保留）
└─────────────────────────┘
```

### 2.1 保留

| 能力 | 呈现位置 |
|------|----------|
| 搜索标题/标签 | 顶部 Search |
| 分类浏览 | 树节点 + 计数 |
| 收藏筛选 | 树底部「★ 收藏」 |
| 我的算法 | 树底部「我的」 |
| 新建 | 底栏主按钮 |
| 导入 / 导出 / 多选 | 底栏「⋯」菜单 |
| 语言筛选 | 底栏紧凑开关（JS / Python / C++） |

### 2.2 去除（首屏噪音）

- 顶部语言 chips 行、收藏/我的 chips 行
- 「全部分类」下拉（树即分类）
- 新建/导出/导入按钮组占满第二行
- 常驻「多选 N 项」横条
- 列表项常显「×」删除（改为 hover / 滑动确认）
- 底部文案「数据保存在本机，可导出备份」（并入「⋯」或设置说明）

### 2.3 交互要点

| 项 | 规则 |
|----|------|
| 默认展开 | 当前算法所属分类自动展开（对齐 AV） |
| 搜索行为 | 命中的分类与算法自动展开；无结果显示空态 |
| 选中态 | 分类路径 + 算法项高亮；分类行可显示当前名 |
| 计数 | 分类标题旁显示匹配/总数，不单独占一行 |
| 删除 | 仅 hover 显示；确认仍用行内二次确认 |
| 多选 | 进入后列表出现勾选；退出恢复树态 |
| 持久化 | `algolab.lib.lang`、分类展开态 `algolab.nav.open`、折叠宽度沿用现有 key |
| 移动端 | 同一树 IA；底栏语言开关可折进「⋯」以省空间 |

## 3. 非目标

- 不改动三栏 dock / 拖拽 / 可视化日志区（已实现，维持现状）
- 不做云端目录同步、不做 AV 的 GitHub/API 外链
- 本说明不包含动画协议迁移（见 VIS_* 文档）

## 4. 验收（实现阶段）

1. 左侧首屏可见：搜索 + 分类树 + 底栏，无 chips 云
2. 点分类展开/收起；选算法后分类保持展开
3. 「收藏」「我的」「语言」过滤结果正确
4. 新建/导入/导出/多选仍可用且不占主列表上方空间
5. 删除不默认露出；多选批量删除可用
6. 窄屏（≤600px）树与底栏不横向溢出

## 1. 信息架构

```
算法库                    [＋文件夹] [＋文件]
Search …
▾ 📁 队列
  │   📄 环形队列          ← 选中
  │   📄 双端队列

────────
  [JS|Py|C++]             ← 仅此处出现语言
  导入 / 导出 / 多选       ← 底栏更多（无「我的」）
```

### 1.1 层级视觉规则

| 元素 | 视觉 |
|------|------|
| 文件夹行 | 中等字重 500、13px、📁 或仅 chevron；整行可点展开 |
| 文件行 | 左缩进 22px + **竖向引导线**；字重 400、12.5px；**无角标** |
| 选中文件 | 左侧 3px 强调条 + 浅色底；删除钮仅 hover/选中出现 |
| 展开指示 | 文件夹左侧 ▸/▾；文件夹名不加粗到与文件同级 |
| 计数 | **默认隐藏**；仅搜索时在文件夹名后显示命中数（可选） |

### 1.2 操作语义

| 操作 | 行为 |
|------|------|
| **＋文件夹** | 在树内新建分类；行内可重命名；持久化到 `algorithm.category` |
| **＋文件** | 在当前打开的文件夹下新建算法；若未展开则先建/选「未命名」文件夹 |
| 重命名文件夹 | 改所有该分类下算法的 `category`（批量 patch） |
| 删除文件夹 | 二次确认；可选「仅移除分类名」或「删除内含算法」（默认前者归入「其他」） |
| 导入/导出/多选 | 移到底栏「更多」，与 v1 相同 |
| 收藏 | 仍作筛选伪节点；不进文件夹重命名逻辑 |

### 1.3 去掉的元数据

- 算法行右侧 **JS/Py/C++ 角标**（语言由底栏过滤 + 选中后代码区可见）
- 文件夹名旁常驻 **N 项**
- 「数据保存在本机…」仍只在「更多」菜单内

# v2.1 计划修订（对照 VS Code 资源管理器 · 待审阅）

## 0. 本版相对 v2 的变更

| 项 | v2 | **v2.1** |
|----|----|----------|
| 新建入口 | 文字按钮「＋文件夹 / ＋文件」 | **图标**工具栏（新建文件夹 / 新建文件），无文字钮 |
| 重命名/删除 | 行内按钮 | **右键菜单**（文件/文件夹/空白区） |
| 创建落点 | 「当前展开文件夹」 | **按选中路径**：无选中→根；选中文件夹→该文件夹下；选中文件→其父文件夹下 |
| 导入导出 | 底栏「更多」内平铺 | **收进同一组**「⋯」或「导入/导出」图标组（对齐 VS Code 更少顶栏图标） |
| 参考 | AV Navigator | **VS Code Explorer** |

## 1. 工具栏（图标，hover 提示）

```
[新建文件夹] [新建文件] [刷新] [折叠全部]
```

- 仅图标（类似 VS Code：new-folder / new-file / refresh / collapse-all）  
- 与右侧「⋯」并列；「⋯」内含：**导入… / 导出…**（一组）+ 多选  

## 2. 右键菜单（对齐 VS Code）

| 目标 | 菜单项 |
|------|--------|
| **文件夹** | 新建文件 · 新建文件夹 · 重命名 · 删除 |
| **文件** | 重命名 · 删除 · 在文件夹中新建文件 |
| **空白区** | 新建文件 · 新建文件夹 · 导入 · 导出 |

- 重命名：行内改名（input）  
- 删除文件夹：确认后默认**解散**到「其他」；高级项可选删除内含算法  
- 删除文件：二次确认  

## 3. 创建落点（路径规则）

```
选中状态              新建文件/文件夹落到
─────────────────────────────────────
无选中                根（顶层分类文件夹下 / 未分类）
选中「文件夹」        该文件夹内
选中「文件」          其**父文件夹**内（与 VS Code 相同）
选中「收藏」筛选      根（收藏不作父节点）
```

## 4. 导入 / 导出收拢

底栏或工具栏「⋯」内：

```
导入…
导出…
────────
多选
```

不单独占用一排文字按钮。

## 5. 仍执行的 v2 决策

- 📁=分类 / 📄=算法；引导线缩进；去条目语言角标与常驻计数  
- **删除「我的」**；保留 ★ 收藏  
- 语言仅底栏 `JS|Py|C++`

## 6. 实现步骤（批准后）

1. 树节点模型 + 选中路径/创建落点逻辑  
2. VS Code 风工具栏图标与右键菜单组件  
3. 行内重命名、删除确认流  
4. 导入/导出收进「⋯」  
5. 视觉（引导线/字重）+ verify 脚本  

## 7. 验收补充

1. 右键文件夹/文件/空白区菜单项正确  
2. 无选中新建→根；选文件夹→子级；选文件→同级  
3. 工具栏仅图标（含新建文件夹、新建文件）  
4. 导入导出同一菜单组  
5. 无「我的」、无条目语言角标
