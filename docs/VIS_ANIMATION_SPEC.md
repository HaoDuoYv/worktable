# 数据结构可视化 —— 动画设计与统计窗口规范

> 版本：v1.0 · 配套 `docs/VIS_SPEC.md`（命令协议）与 `src/core/av/renderers.tsx`（渲染层）
> 本文定义**视觉与动效层**：每种数据结构的操作动画语义 + 统计信息浮动窗口规范。

---

## 1. 目标

在现有「数组元素以柱状/单元格表示」的视觉基础上，为 9 类数据结构统一设计**插入 / 删除 / 查找 / 遍历**四类核心操作的直观动画，并新增一个**实时统计浮动窗口**，随回放步进更新元素数量、容量、操作次数与执行状态。

---

## 2. 统一动画语言

### 2.1 状态色语义（沿用现有 token，不新增色值）

| 状态 | 色 token | 语义 | 典型操作 |
|------|----------|------|----------|
| 比较 / 选中 | `--accent`（蓝） | 当前正在比较、命中或聚焦的元素 | 查找、比较 |
| 写入 / 交换 | `--signal`（青绿） | 刚被写入、交换、插入或更新的元素 | 插入、交换 |
| 访问 / 已遍历 | `--signal`（青绿，描边） | 已访问过的节点/边 | 遍历 |
| 删除 / 移除 | `--danger`（红） | 即将或正在移除的元素 | 删除 |
| 结构标记 | `--warn`（黄） | head / tail / 根 / 空槽 | 环形队列头尾 |

> 无障碍：**不得仅以颜色传达状态**。颜色必须与位置、箭头、head/tail 标签、`title` 提示等至少一种非颜色线索并存（见 §5）。

### 2.2 动效参数（克制原则）

| 项 | 值 |
|----|----|
| 时长 | 200–280ms（删除可到 300ms） |
| 缓动 | `cubic-bezier(0.2, 0.8, 0.2, 1)`（`--ease-ui`） |
| 仅动画属性 | `transform`、`opacity`、`box-shadow`（GPU 加速） |
| 循环 | 遍历涟漪 1 次；状态呼吸 ≤ 1.5s 无限 |
| `prefers-reduced-motion` | 全局禁用（tokens.css 已覆盖） |

关键帧（已实现于 `algo-lab.css`）：

| 关键帧 | 用途 | 操作 |
|--------|------|------|
| `viz-op-insert` | 弹入（scale 0.5→1.06→1 + 淡入） | 插入 |
| `viz-op-delete` | 收缩消失（scale→0.3 + 淡出） | 删除 |
| `viz-op-search` | 扫描高亮（box-shadow 脉冲） | 查找/比较 |
| `viz-op-traverse` | 涟漪（scale 1→1.18→1） | 遍历/访问 |
| `viz-flash-patch` / `viz-pulse-select` | 写入闪光 / 选中上浮（既有） | 写入/选中 |

## 3. 各数据结构动画规格

> 视觉形态沿用现有 renderer：一维结构用**单元格**（柱状可转单元格语义），图/树用 **SVG 节点 + 边**。

### 3.1 线性队列（QueueTracer · 横向 front→back）

- 形态：横向单元格，左 `front` 右 `back` 标签。
- **插入（enqueue）**：新元素从右侧**弹入**（`viz-op-insert`），`back` 标签右移到新尾。
- **删除（dequeue）**：队首元素**收缩淡出**（`viz-op-delete`），后续元素整体左移，`front` 标签右移。
- **查找**：自 front 向 back **扫描高亮**（`viz-op-search`）逐格亮起。
- **遍历**：同查找，但命中元素短暂**涟漪**（`viz-op-traverse`）后恢复。

### 3.2 环形队列（CircularQueueTracer · 环形槽位）

- 形态：环形槽位（`viz-ring`），`H`(head) / `T`(tail) 标签标注入队口与出队口。
- **插入**：tail 槽位元素**弹入**并变青，`T` 标签顺时针移到下一空槽。
- **删除**：head 槽位元素**收缩淡出**，槽位变空点 `·`，`H` 标签顺时针前移。
- **查找/遍历**：沿环顺时针**扫描**槽位，命中/访问槽位**涟漪**。
- 关键：head/tail 标签移动是环形队列最核心的「位置变化」信号，必须可见。

### 3.3 静态链表（StaticLinkedListTracer · data/next 双行表）

- 形态：`data` 行（元素值）+ `next` 行（后继下标）二维表。
- **插入**：新行的 `data` 格**弹入**，随后 `next` 格高亮写入后继下标（扫描高亮 + 写入闪光）。
- **删除**：被删格 `data` 变空并**收缩**，其前驱的 `next` 格被改写（高亮新值）。
- **查找**：沿 `next` 指针链**逐格扫描**——当前 `next` 格高亮，跳转到下一行时对应格**涟漪**，清晰呈现「下标跳转」。
- **遍历**：同查找，额外用 `--warn` 标记起点（如 `head=0`）。

### 3.4 链表（LinkedListTracer · 节点 + 指针箭头）

- 形态：节点（值 + 右侧指针点）+ `→` 箭头，末尾 `∅`。
- **插入**：新节点在目标位置**弹入**，断开的箭头先淡出、重连箭头再淡入（`opacity` 过渡）。
- **删除**：被删节点**收缩淡出**，其前后箭头合并重连。
- **查找**：自头节点起**逐个涟漪**，当前节点高亮、指针箭头变亮。
- **遍历**：节点依次**涟漪**，边（箭头）随访问进度变色。

### 3.5 栈（StackTracer · 纵向 top→bottom）

- 形态：纵向单元格，顶部 `top` 底部 `bottom`。
- **插入（push）**：新元素从**顶部弹入**，原元素整体下移，`top` 标签始终指向新顶。
- **删除（pop）**：栈顶元素**收缩淡出**，`top` 标签下移。
- **查找/遍历**：自 top 向 bottom 逐格**扫描 + 涟漪**。

### 3.6 树（TreeTracer / GraphTracer · 节点 + 父子边）

- 形态：SVG 节点 + 有向边（父→子），根无父边。
- **插入**：新节点**弹入**于父节点下方，父→子边**淡入**。
- **删除**：节点**收缩淡出**，其边同时淡出，子树重连边淡入。
- **查找**：沿比较路径**节点涟漪 + 边变亮**，命中节点**扫描高亮**定格。
- **遍历**（前/中/后/层序）：访问节点**涟漪**、边标记 `is-visited`（青），清晰呈现遍历顺序。

### 3.7 红黑树（RedBlackTreeTracer · 节点红/黑着色）

- 形态：节点圆着色（红/黑）+ 边。
- **插入**：新节点**弹入**（初始红），随后**旋转/变色**步骤中相关节点**涟漪**并**颜色过渡**（红↔黑，`fill` 过渡）。
- **删除**：节点**收缩淡出**，其后的**旋转**（rotateLeft/Right）通过节点位置 `transform` 平滑过渡、边重连淡入。
- **查找**：沿比较路径**涟漪**，命中节点定格**扫描高亮**。
- **遍历**：同普通树，但保留红/黑着色作为结构约束的视觉线索。

### 3.8 B 树（经 TreeTracer 呈现）

> 当前引擎无 `BTreeTracer`；B 树以 **TreeTracer/GraphTracer** 呈现，节点 label 形如 `10|20`。

- **插入**：满节点**分裂**——新节点**弹入**、中间键**上浮**（节点沿边 `transform` 上移）、边重连淡入。
- **删除**：节点**收缩淡出**，**借位/合并**时键在相邻节点间平移（`transform`）。
- **查找**：自根逐层**扫描节点内键**（多键节点逐键涟漪），沿边下钻。
- **遍历**：按中序/层序访问节点**涟漪**。

### 3.9 B+ 树（BPlusTreeTracer · 节点 + 叶层链表）

- 形态：内部节点（索引键）+ 叶节点（数据键），叶层间可呈现**左右指针链**。
- **插入**：叶节点写满触发 `split`——新叶**弹入**、键**上浮**到父节点、叶层链表指针重连淡入。
- **删除**：叶节点键**收缩淡出**，可能触发**借位/合并**（键平移 + 节点位置过渡）。
- **查找**：自根沿索引键**逐层扫描 + 下钻**，命中叶节点后沿链表**横向扫描**。
- **遍历**：沿叶层链表**顺序涟漪**（区间查询语义）。

## 4. 统计信息浮动窗口

### 4.1 字段

| 字段 | 来源 | 说明 |
|------|------|------|
| 元素数量 | 非日志 Tracer 的有效值计数 | 空值/占位 `·` 不计 |
| 当前容量 | `capacity` / 数组长度 / 静态链表长度 | 无固定容量显示「无限制」 |
| 操作次数 | 日志文本关键词计数 | 插入/删除/查找/比较/交换/遍历 分项 + 总和 |
| 执行状态 | 回放上下文 | 待运行/构建中/运行中/已暂停/已完成 |

> 实现：`src/core/av/stats.ts`（纯函数 `computeVizStats`）+ `src/components/VizStatsPanel.tsx`（可拖动浮动窗口）。

### 4.2 布局与交互

- **位置**：默认悬浮于画布右上角；标题栏（六点手柄）**可拖动**，拖动范围约束在面板内。
- **折叠**：标题栏右侧 `−`/`+` 可收起/展开为一行标题条。
- **实时刷新**：随 `cursor`/`tracers` 步进重算；数值变化时窗口外框**高亮闪烁 0.4s**（`is-flash`），提示更新。
- **状态色**：状态圆点按语义着色（运行/完成=青、暂停/构建=黄、待机=灰），呼吸动画仅用于「运行/构建中」。

### 4.3 响应式

| 断点 | 行为 |
|------|------|
| ≥ 601px | 右上角浮动卡片（`min(240px, 100%-24px)`），可拖动/折叠 |
| ≤ 600px | 贴顶紧凑横条（`left/right: 8px`），数值行横向排列，操作分项换行，仍可折叠 |

### 4.4 无障碍

- 使用 `<div role="region" aria-label="数据结构统计">` 标记。
- 状态圆点旁**始终有文字标签**（不单靠颜色）。
- 数值用等宽字体 + `tabular-nums`，对齐稳定。
- 拖动手柄为 `grab/grabbing` 光标 + `touch-action: none`；移动端折叠按钮触控目标 ≥ 22px。
- 高亮闪烁遵循 `prefers-reduced-motion` 降级。

## 5. 无障碍检查清单（WCAG 2.2 AA）

- [x] 状态不单靠颜色：head/tail 标签、指针箭头、`title` 提示、空槽 `·` 与颜色并存
- [x] 对比度：正文 ≥ 4.5:1，次要信息 ≥ 4.5:1，装饰/元信息 ≥ 3:1
- [x] 动效仅 `transform`/`opacity`/`box-shadow`，`prefers-reduced-motion` 全局关闭
- [x] 键盘可达：折叠按钮为原生 `<button>`；统计窗口为 `region` 语义
- [x] 焦点可见：`:focus-visible` 全局 outline（tokens.css）
